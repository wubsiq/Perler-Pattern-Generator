# 16-已有工具库-js

## 来源
- 原目录: `js`

## 文件列表

| 文件 | 说明 |
|------|------|
| `colors.js` | 颜色数据（全部Mard/Perler/COCO色板定义） |
| `colorUtils.js` | 颜色工具（空间转换、距离计算、量化） |
| `i18n.js` | 国际化（中英双语资源） |
| `brushManager.js` | 画笔管理器（新建/选择/保存/变换） |
| `brushPanel.js` | 画笔管理面板（UI + 事件） |
| `BrushLibraryManager.js` | 画笔库管理器（预设画笔加载） |
| `SelectionManager.js` | 选区管理器（创建/变换/保存画笔/skipTransparent） |
| `SelectionPanel.js` | 选区面板（UI + 勾选框事件） |
| `bead-palette.js` | 色板UI组件 |
| `script.js` | 旧脚本（可能遗留） |
| `circular-app.js` | 圆形拼豆独立应用 |
